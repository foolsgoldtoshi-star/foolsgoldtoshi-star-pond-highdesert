## 🔧 **TECHNICAL ARCHITECTURE BLUEPRINT**

### **Core Technologies Stack**
- **ClojureScript 1.12.42** - Functional programming with immutable data structures
- **Svelte 5.39.6** - Reactive frontend components with modern features
- **Babashka** - Task orchestration and build pipeline management
- **Nix/NixOS** - Reproducible development environments and deployment
- **GitHub Pages** - Static site deployment with automatic CI/CD

### **Phoenix DSL Pipeline** 
```clojure
;; Sacred transformation pipeline
(-> markdown-teachings
    (phoenix/parse-with-spec)      ; docs/en/*.md → ClojureScript data
    (phoenix/validate-consciousness) ; clojure.spec validation
    (phoenix/transform-to-svelte)   ; Data → Svelte components  
    (svelte/serve-awareness))       ; Reactive web application
```

### **Build System Architecture (bb.edn)**
```bash
# Nix-first approach (prefer Nix packages, fallback to npm only when necessary)
bb doctor                    # Toolchain verification with Nix package recommendations
bb nix:dev-shell            # Enter reproducible development environment
bb nix:check-packages       # Audit package availability (Nix vs npm)

# Phoenix DSL Pipeline
bb phoenix:parse            # Markdown → ClojureScript data (with ecological caching)
bb phoenix:spec             # clojure.spec validation of consciousness data
bb phoenix:generate         # Data → Svelte components generation
bb build:phoenix-gen        # Complete pipeline execution

# Development & Deployment  
bb serve:localhost          # Local development (Nix-first, npm fallback)
bb build:pages              # GitHub Pages static build
bb build:aws-server         # NixOS container for AWS EKS production
bb deploy:aws-eks           # Production deployment with udw firewall

# Quality Assurance
bb lint:kondo               # Code quality with consciousness
bb fmt:zprint               # 80-column formatting for contemplative reading
bb ci:verify                # Complete verification pipeline
```

### **Ecological Efficiency Features**
- **Intelligent caching** with file modification timestamps
- **Memoized template loading** reducing I/O operations
- **Pure functional composition** with separated side effects
- **Resource conservation feedback** ("🌱 Parsed and cached" indicators)
